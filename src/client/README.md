# `src/client/`

React + TypeScript + Vite frontend.

- `index.html` — Vite root document
- `src/main.tsx` — React entry, mounts `<App />`
- `src/App.tsx` — minimal full-viewport app shell
- `src/components/` — small shared components
- `src/styles/` — global styles for the shell

Later phases will add `app/`, `features/wall/`, `features/filters/`,
`features/modal/`, `hooks/`, and `state/` per `01-architecture.md`.
