# Work

Use this folder for temporary execution state.

## Areas

- `plans/` — multi-step temporary plans and migration slices
- `tasks/` — task-level working notes and handoff packets
- `archived/` — completed temporary work worth keeping briefly for reference

Nothing here is canonical by default.

If something becomes durable enough to rely on, promote it into `docs/` or `AGENTS.md`. Durable parked ideas can move into `docs/workshop-ideas/` even when they are not approved behavior yet.

Do not leave convergence here once it matters repeatedly. If the human and agent aligned on a durable goal, rule, term, or procedure, promote that converged understanding into canonical docs.

For non-trivial temporary work, prefer a small convergence block:

- `Converged intent`
- `Non-goals`
- `Open uncertainties`
