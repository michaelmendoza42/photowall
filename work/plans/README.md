# Plans

Use this folder for temporary multi-step plans, migration slices, and other active execution scaffolding.

Plans here are drafts by default.

If a plan produces durable product, workshop-idea, system, standards, runbook, or decision knowledge, promote that result into canonical docs.

Plans are allowed to be messy while convergence is still happening. Once the user and agent reach durable alignment, preserve the result canonically rather than keeping it trapped in planning notes.

For non-trivial plans, include a compact convergence block near the top:

- `Converged intent`
- `Non-goals`
- `Open uncertainties`
