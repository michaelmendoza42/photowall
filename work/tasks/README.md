# Tasks

Use this folder for task-level working state such as:

- ticket execution notes
- handoff checkpoints
- short-lived task breakdowns
- validation notes tied to one change

Task docs are temporary by default.

For non-trivial tasks, include:

- `Converged intent`
- `Non-goals`
- `Open uncertainties`

If a task note reveals a durable rule, parked idea, decision, or converged behavior expectation, promote it into canonical docs.
